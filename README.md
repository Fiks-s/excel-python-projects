# Excel + Python: обработка продаж

Два подхода к одной задаче — сборка свода продаж из множества Excel-файлов.

## 📁 Проекты

- **[excel-pq-sales](./excel-pq-sales)** — свод через Power Query в Excel.
- **[python-sales-report](./python-sales-report)** — свод через Python-скрипт с логированием и автоформатированием.

## 🛠 Что умеют проекты

- Читают все `.xlsx`-файлы из папки.
- Определяют город и квартал из имени файла.
- Исправляют опечатки в названиях товаров.
- Проверяют даты и предупреждают о расхождениях.
- Удаляют дубли.
- Строят свод по сумме (руб.) и количеству (шт.).
- Форматируют итоговый Excel (границы, заливка, шрифты).
