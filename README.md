# Excel + Python: обработка продаж

Два подхода к одной задаче — сборка сводных продаж из множества Excel-файлов.

## 📁 Проекты

- **[excel-pq-sales](./excel-pq-sales)** — сводный отчёт, собранный в Excel через Power Query.
- **[python-sales-report](./python-sales-report)** — сводный отчёт на Python с логированием и автоформатированием.

## 🛠 Что умеют проекты

- Читают все `.xlsx`-файлы из папки.
- Определяют город и квартал по имени файла.
- Исправляют опечатки в названиях товаров.
- Находят невалидные даты (например, `31.13.2026`) и исправляют их.
- Удаляют дубли.
- Строят свод по сумме (руб.) и количеству (шт.).
- Форматируют итоговый Excel (границы, заливка, шрифты).
