# Свод продаж — Python

Скрипт собирает данные о продажах из множества Excel-файлов в один сводный отчёт с автоматическим форматированием.

## Что делает

1. Находит все `.xlsx` в текущей папке.
2. Определяет город и квартал из имени файла.
3. Читает строки, чистит числа, исправляет опечатки в названиях товаров.
4. Проверяет даты: если дата не попадает в квартал из имени файла — пишет предупреждение, но использует квартал из имени.
5. Удаляет дубли.
6. Строит свод по сумме (руб.) и количеству (шт.).
7. Форматирует итоговый файл: границы, заливка, шрифты.

## Требования

- Python 3.8+
- pandas
- openpyxl
